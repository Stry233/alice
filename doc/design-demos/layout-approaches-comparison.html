Alice Studio: Layout Architecture

Three approaches for a Gotham-style operational interface. All share the same Blueprint-inspired component design — the difference is how panels are organized.

A

Mission Control Single-Screen

Everything visible at once. No tabs, no navigation.

+========================================================================+
| ALICE STUDIO        [MF] [AF-S] [AF-C] [AF-F]    Motor:OK Depth:OK Sync:-- |
+========================================================================+
|                                        |  MOTOR CONTROL            |
|                                        |  [========|====] 2048     |
|         CAMERA FEED                    |  [1] [2] [3] [4] [5]     |
|         (16:9, fills space)            |---------------------------|
|                                        |  DEPTH         2.34m 92% |
|                                        |  +-------------------+   |
|                                        |  | RealSense RGB     |   |
|                                        |  | with crosshair    |   |
|                                        |  +-------------------+   |
|                                        |---------------------------|
|                                        |  CALIBRATION              |
|                                        |  [Select Preset... v]     |
|                                        |  [Load] [Clear]           |
+========================================================================+
| Depth: 2.341m | Conf: 92% | Motor: 2048/4095 | Mode: AF-C | 30fps    |
| [LOG] 14:32:01 [INFO] Motor moved to 2048                             |
+========================================================================+

Pros

  • Zero navigation — everything always visible
  • Camera feed + motor + depth all in one glance
  • Simplest to build and maintain
  • Feels like a monitoring station

Cons

  • Settings & calibration crammed into sidebar or accessed via dialogs/drawers
  • Fixed layout — no customization
  • Connection/QR code needs a popup or overlay
B

Dual-Mode: Operational + Configuration

Two distinct modes. "OPS" is a dense single-screen for shooting. "CONFIG" opens calibration, settings, and connection setup.

OPS MODE (default — where you spend 95% of time):
+========================================================================+
| ALICE STUDIO   [OPS|CFG]   [MF][AF-S][AF-C][AF-F]   Motor:OK Depth:OK |
+========================================================================+
|                                        |  MOTOR         [2048]     |
|                                        |  [===========|===] 2048   |
|         CAMERA FEED                    |---------------------------|
|         (maximized)                    |  DEPTH FEED               |
|                                        |  +---------+ 2.34m       |
|                                        |  |RealSense| 92% conf    |
|                                        |  +---------+             |
+-------------------------------------  |---------------------------|
| Depth: 2.34m | Motor: 2048 | AF-C     |  HISTOGRAM    |  LOG      |
| Target: 2050 | Conf: 92%   | 30fps    |  [===]        |  14:32... |
+========================================================================+

CFG MODE (press CFG or Ctrl+,):
+========================================================================+
| ALICE STUDIO   [OPS|CFG]                    Motor:OK Depth:OK |
+========================================================================+
| [Calibration] [Settings] [Connection]                                  |
|                                                                        |
|   Full-width calibration / settings / connection panels                |
|   with live device status sidebar on the right                         |
|                                                                        |
+========================================================================+

Pros

  • OPS mode is maximally dense — no wasted space on rarely-used features
  • Clean separation: shooting vs. configuring
  • Config mode gets full screen real estate for calibration graphs, QR codes, settings
  • Matches your actual workflow (monitor 95%, configure 5%)

Cons

  • Mode switching adds one click when you need settings
  • Two layouts to design and maintain
C

Tiled Panels with Splitters

Gotham-style tiled layout where every panel is resizable via 1px splitter handles. Panels can be collapsed to make more room for what matters.

+========================================================================+
| ALICE STUDIO   [MF][AF-S][AF-C][AF-F]          Motor:OK Depth:OK Sync |
+===================================|====================================+
|                                   |  DEPTH FEED          |  MOTOR     |
|                                   |  +-------------+     |  [===|==]  |
|      CAMERA FEED                  |  | RealSense   |     |  2048      |
|      (resizable)                  |  | + crosshair |     |  [1][2]..  |
|                                   |  +-------------+     |            |
|                               |<-splitter->|           |<-splitter->|
|---splitter-----------------------|  2.34m  92% conf     |  CALIB     |
|  TELEMETRY      |  LOG            |  Target: 2050        |  Active:.. |
|  Depth: 2.34m   |  14:32 [INFO].. |                      |  [Preset]  |
|  Motor: 2048    |  14:32 [INFO].. |  HISTOGRAM           |  [Load]    |
|  Mode: AF-C     |  14:31 [WARN].. |  [====]              |  [Clear]   |
+========================================================================+

Pros

  • Most flexible — user can resize panels to preference
  • True Gotham/mission-control feel with tiled data panels
  • Panels can be collapsed when not needed

Cons

  • Most complex to implement in Qt Quick (SplitView nesting)
  • Layout state management (save/restore sizes)
  • Risk of looking cluttered if not carefully tuned
  • Settings/Connection still need a dialog or overlay

My Recommendation: B (Dual-Mode)

It matches your workflow exactly — 95% monitoring in a maximally dense OPS screen, with full-screen space for calibration/settings/connection when needed. It's the sweet spot between the simplicity of A and the flexibility of C, without the implementation complexity of resizable splitters. The OPS mode itself borrows the tiled, Gotham-style density feel. Connection/QR naturally lives in the CONFIG mode, and status badges in the toolbar handle the "is it connected?" question during OPS.
